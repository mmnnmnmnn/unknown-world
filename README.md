# 개막식 참여형 웹콘텐츠 — 3단계 Scene 1 수정본(2차)

이번 수정본은 모바일 피드백을 반영하여 Scene 1의
카메라 시야, 지구본/관측자 배치, 우주선 전환/비행 경로를 다시 조정한 버전입니다.

## 이번에 추가 반영한 내용

1. 지구본 위치 재조정
   - 지구본을 조금 더 위로 올림
   - 관측자가 지구를 밟고 서 있는 느낌으로 배치

2. 카메라 시야 구조 변경
   - 초반: 관측자 중심 확대
   - 다음: 오른쪽으로 이동하며 기본 우주선 중심 보기
   - 이후: 줌아웃하며 상단 오브젝트 공개

3. 기본 우주선 동작 수정
   - 기본 우주선은 등장 후 launch 전까지 정지
   - 기본 위치를 조금 더 왼쪽으로 이동

4. 점화 우주선 전환 수정
   - 점화 우주선은 기본 우주선보다 살짝 아래에서 시작
   - 내부 이미지 크기를 1.5배 확대
   - 페이드 없이 순간 전환

5. 구름 생성 타이밍 재수정
   - 점화 우주선 전에는 구름이 보이지 않음
   - launch 전환 직후 좌우 구름 생성
   - 작은 구름은 우주선 하단에서 생성되어 왼쪽으로 확산

6. 점화 우주선 이동 경로 조정
   - 처음 약 2초는 느리게 이동
   - 이후 가속
   - 화면 중앙 쪽을 지나며 좌측 화면 밖으로 퇴장
   - opacity 페이드 아웃 대신 실제 이동으로 화면 밖 퇴장

## 주요 교체 파일

- `css/common.css`
- `js/mobile.js`
- `README.md`

나머지 구조와 에셋은 이전 ZIP과 동일합니다.

## 테스트 포인트

- 관측자가 지구 위에 자연스럽게 서 있는지
- 카메라가 먼저 관측자를 충분히 보여주는지
- 이후 카메라가 우주선 쪽으로 확실히 이동하는지
- launch 전에는 구름이 전혀 보이지 않는지
- 기본 우주선은 정지 상태인지
- 점화 우주선이 더 크게 보이는지
- 점화 직후 느리게 출발한 뒤, 후반부에 가속하는지
- 파란 의도 동선에 더 가까워졌는지
