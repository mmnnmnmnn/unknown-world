# Scene 2~4 수정본 v17

## 이번 버전 반영 사항
1. **중간 은하 이미지 교체**
   - 사용자가 제공한 0.8배 축소본으로 교체
   - 파일: `assets/scene02-milkyway/galaxy-closeup-rotating-v17.png`

2. **중간 은하 회전 방식 변경**
   - 나타나는 순간부터 사라질 때까지 계속 **시계방향으로 천천히 회전**
   - 총 노출 시간(5.75초) 동안 약 **30도** 회전
   - fade-in / hold / fade-out 전 구간 내내 동일하게 적용

3. **중간 은하 표시 배율 확대**
   - 축소본을 사용하므로 화면에서는 더 확대해서 사용
   - closeup zoom: `1.86 → 1.38`

4. **캐시 무효화**
   - CSS 버전 문자열을 `scene4-v17`로 변경
   - JS 파일을 `mobile-scene4-v17.js`로 분리하여 모바일 캐시 문제를 줄임

## 유지되는 사항
- Scene 3 은하단 배경: 고해상도 원본 회전본 유지
- Scene 3 전체 은하단 줌아웃 속도: 기존 대비 1.5배 빠른 상태 유지
- Scene 4 연출 및 UnTaza 폰트 유지
