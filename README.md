# v20 — UnTaza 임베드 + Scene 3 수정본

## 반영 내용

### 1) 폰트
- Stylish 진단 방식이 성공한 것을 바탕으로, 이번 버전은 **UnTaza.ttf를 CSS에 직접 임베드**했습니다.
- 별도 font 파일 요청 없이 로드되므로, 경로/캐시/CORS 문제를 크게 줄입니다.
- 앱 전체 UI 텍스트에 `UnTazaEmbedded`를 강하게 적용합니다.

### 2) Scene 3 수정
- **중간 은하 이미지**는 계속 천천히 회전합니다.
- 다만 회전 종료 시점(10.45s) 이후 더 이상 2초 이상 정지하지 않고,
  **즉시 은하단 이미지로 전환**되도록 짧은 crossfade(0.4s)로 바꿨습니다.
- 즉, 중간 은하의 정지/대기 구간을 삭제해 총 재생 시간이 짧아졌습니다.

### 3) 은하단 시작 확대
- Scene 3 시작 시 타깃 은하의 크기를 **기존 시작 배율 14 → 42**로 올려
  **약 3배 더 크게** 시작하도록 조정했습니다.
- 이후 최종 전체 은하단 화면으로 줌아웃되는 구조는 유지합니다.
