# Scene 1 v4 — 우주선 전환 구조 수정 + 전체 지구본 교체

## 이번 버전 핵심
- 점화 우주선이 안 보이던 문제 해결
- 기본 우주선과 점화 우주선을 완전히 분리
- 1ms opacity 전환 제거
- requestAnimationFrame 기반 절대시간 런타임으로 Scene 1 재구성
- 새 전체 지구본 이미지(`globe-full-v4.png`)로 교체
- 우주선은 화면 밖 퇴장 대신 `(10, 20)` 좌표에서 작은 점처럼 남음
- 우주선이 먼 점이 된 뒤 2초간 전체 장면 유지

## 원인과 수정
기존 버전은
1. 기본 우주선과 점화 우주선을 같은 구조 안에 묶고,
2. 8.9초 시점에 1ms opacity 애니메이션으로 점화 우주선 표시를 시도했습니다.

이 방식은 모바일에서 프레임 타이밍에 따라 점화 우주선이 끝까지 `opacity: 0`에 머무를 수 있어
"기본 우주선은 사라졌는데 점화 우주선이 안 나타나는" 증상이 날 수 있었습니다.

이번 버전은:
- `#rocketIdle` 과 `#rocketLaunch` 를 HTML에서 분리
- Scene 시간에 따라 명시적으로 표시/숨김 처리
- 점화 우주선 이동도 독립적으로 계산

## 주요 시간
- 지구본 등장: 0.8s ~ 1.8s
- 관측자 등장/기립: 2.8s ~ 5.0s
- 기본 우주선 등장: 7.3s ~ 7.65s
- 점화 전환: 8.9s
- 점화 후 정지: 8.9s ~ 9.9s
- 점화 우주선 이동 시작: 9.9s
- 가속 시작: 11.9s
- 최종 먼 점 좌표 도달: 13.85s (`10, 20`)
- 전체 화면 유지: 13.85s ~ 15.85s
