# Scene 2 + Scene 3 마무리 v10

이번 버전은 아래 3가지를 반영했습니다.

## 1. 은하 이미지 회전
- 기존 v9: 0.25초
- 이번 v10: **0.75초**
- 구간:
  - 시작 `11.20s`
  - 종료 `11.95s`
- 회전 완료 후에는 각도가 고정되고 더 이상 회전하지 않습니다.

## 2. 은하단 Zoom Out / 중앙 이동
- closeup galaxy가 완전히 사라진 뒤에만 시작
- **Zoom Out 먼저 시작**
- **0.5초 뒤 중앙 이동 시작**
- 구간:
  - Zoom Out 시작 `13.95s`
  - 중앙 이동 시작 `14.45s`
  - 둘 다 종료 `17.75s`

즉 초반 0.5초 동안은 같은 타깃 은하를 기준으로 시야가 먼저 멀어지고,
그 후 화면 중심으로 이동하면서 전체 은하단 구도를 잡습니다.

## 3. Scene 4 직전 장면까지 작성
- Scene 3 은하단 전체 화면 완성 후
- 텍스트 **"보이지 않는 우주,"** 가 등장
- 구간:
  - 텍스트 등장 `18.10s ~ 18.85s`
  - 이후 Scene 4 직전 구도 유지
- 현재 개발 단계에서는 이 장면까지 보여준 뒤,
  임시로 입력 화면으로 넘어갑니다.

- `9.7 ~ 11.2s` : closeup galaxy 유지

- `13.95 ~ 17.75s` : cluster Zoom Out
- `14.45 ~ 17.75s` : cluster 중앙 이동
- `18.10 ~ 18.85s` : "보이지 않는 우주," 등장
