## Mobile v18 — Scene 14 keyboard stabilization / Scene 10 timing
- Scene 14 진입 순간의 viewport 크기를 고정하여 키보드가 올라와도 9:16 전체 장면이 축소되지 않습니다.
- `visualViewport`를 지원하는 브라우저에서는 키보드로 가려지는 높이를 감지합니다.
- 키보드가 입력창을 가릴 때 Scene 14 전체가 아니라 질문/닉네임/제출 버튼이 포함된 `response-form` 레이어만 위로 이동합니다.

- 키보드가 닫히면 입력 영역은 원래 위치로 복귀합니다.
- `외계생명체 혹은 / 신의 존재?` Scene 10의 완전 표시 시간을 1초 추가했습니다.

## Mobile v20 — Scene 4 → 5 중간 통로 이미지
- 첨부한 녹색 그라데이션 이미지를 `assets/scene05-future/scene4-5-bridge.png`로 추가했습니다.
