# Scene 1 — WORLD 좌표계 + 독립 절대 타임라인 리팩터링

이번 버전은 단순 위치 미세조정판이 아니라 Scene 1의 구조를 다시 정리한 버전입니다.

## 핵심 변경

### 1. 고정 WORLD 좌표계
- `star-chart-bg.png`를 Scene 1의 기준 평면으로 사용
- 배경 자체의 독립 drift 제거
- WORLD 좌표: 왼쪽 위 `(0, 0)`, 오른쪽 아래 `(100, 100)`
- 모든 오브젝트의 위치와 비행 경로는 이 WORLD 좌표만 사용
- CAMERA가 움직여도 실제 오브젝트 좌표는 바뀌지 않음

### 2. 요소별 독립 절대 시간
각 요소는 Scene 시작 `0 ms` 기준 시간을 독립적으로 가집니다.

현재 주요 값:
- 지구본 등장: `0.8s`
- 관측자 등장: `2.0s`
- 기본 우주선 등장: `5.5s`
- 점화: `7.0s`
- 좌/우 구름: `7.4s`
- 작은 구름: `7.6s`
- 상단 오브젝트 생성: `7.6s`
- 우주선 가속 시작: `9.0s`
- 우주선 화면 밖 퇴장: `10.65s`
- 전체 Zoom Out 완료: `10.8s`
- Scene 종료: 마지막 이벤트에서 계산 (`12.5s`)

### 3. 기본 우주선 / 점화 우주선
- 기본 우주선 WORLD 위치: 약 `(73, 79)`
- 기본 우주선은 등장 후 점화 시점까지 위치 변화 없음
- 점화 시 `rocket-idle` → `rocket-launch` 순간 전환
- 점화 우주선만 1.5배 확대
- 점화 우주선은 이미지 길이를 고려해 내부적으로 약간 아래 배치
- 우주선 이동은 점화 시각 `7.0s`부터만 시작

### 4. 구름
- 점화 `7.0s`
- 좌/우 구름 `7.4s`
- 작은 구름 `7.6s`
- 각 구름은 별도의 `delay`를 사용하므로 점화 전에 애니메이션이 실행되지 않음

### 5. 우주선 비행 경로
`ROCKET_PATH`에 WORLD 좌표를 직접 기록합니다.

초기안:
- `(73,79)`
- `(74,73)`
- `(73,65)` — 여기까지 약 2초간 천천히
- `(69,57.5)` — 가속
- `(62,50.5)`
- `(51,43.5)`
- `(34,37.5)`
- `(-12,32)` — 좌측 화면 밖 퇴장

초반에는 우측 영역을 유지하여 이전 버전처럼 중앙으로 과도하게 들어오지 않도록 조정했습니다.

### 6. CAMERA
CAMERA는 WORLD 좌표와 완전히 분리했습니다.

- 초반: 전체
- 관측자 등장 시 `(30,75)` 중심, 약 2.35배 Zoom
- 이후 우주선 `(73,75)` 쪽으로 Pan
- 점화/구름 연출 후 전체 `(50,50)`로 Zoom Out

관측자 → 빈 공간 → 우주선이 아니라,
관측자를 충분히 본 후 우주선을 직접 보는 구조입니다.

### 7. 상단 오브젝트
- 여인 / 신 / 목성 / 초록 행성 / 토성 / 나방은 `7.6s`부터 생성
- 이때 CAMERA는 우주선 근처를 확대하고 있어 상단 생성 과정은 보이지 않음
- Zoom Out이 시작될 때는 이미 대부분 생성 완료 상태
- 여인과 신에는 미세한 상하 부유 효과 유지

## 앞으로 미세조정할 위치

`js/mobile.js` 상단의 아래 3개 영역만 보면 됩니다.

### WORLD_LAYOUT
정적인 위치와 크기 수정:
```js
rocket: { x: 73.0, y: 79.0, width: 21 }
```

### ELEMENT_TIMELINE
등장/전환/이동 시간 수정:
```js
rocket: {
  appear: 5500,
  ignite: 7000,
  accelerate: 9000
}
```

### ROCKET_PATH
우주선 실제 경로 수정:
```js
{ time: 9000, x: 73.0, y: 65.0 }
```

따라서 이후에는 예를 들어
- "기본 우주선 x=73 → 70"
- "구름 7.4초 → 7.9초"
- "P3 x=62 → 66"
처럼 수정하면 다른 요소를 흔들지 않고 조절할 수 있습니다.
