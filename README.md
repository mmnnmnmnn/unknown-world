# Scene 4 수정본 v15

## 반영 내용
1. **두 번째 물고기 떼 경로 수정**
   - 같은 asset을 좌우 반전해서 사용
   - 이동 경로를 **우 → 좌하단 대각선**으로 변경
   - 머리 방향도 살짝 아래를 향하도록 회전값 수정

2. **고래 수정**
   - 크기 **1.5배 확대**
   - 이동 속도를 이전보다 훨씬 느리게 조정
   - 우측으로 퇴장하지 않고 화면 안에 계속 남도록 수정
   - 고래 등장 이후에도 카메라 상승과 오징어 연출이 겹쳐 진행

3. **고래 등장 이후 구간 1.3배 확장**
   - 고래 등장 시점(7.35초) 이후부터 Scene 4의 동작 연출 구간을 1.3배 느리게 조정
   - 느려진 대상: 고래 이동, 카메라 상승, 대왕오징어 이동/축소/퇴장
   - 마지막 문구의 **완전 표시 후 유지시간 3.4초는 그대로 유지**

4. **대왕오징어 수정**
   - 등장 시 더 큰 크기로 시작
   - 이후 좌측 이동과 축소 연출은 유지
