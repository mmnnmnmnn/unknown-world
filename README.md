# Scene 3 은하단 교체 + 폰트 변경 + Scene 4 유지본 v16

## 이번 버전 핵심 반영
1. **Scene 3 은하단 배경 교체**
   - 사용자가 제공한 고해상도 원본(11699×7326) 기준
   - **90도 시계 방향 회전** 후 사용
   - Scene 3 확대 타깃을 사용자가 표시한 작은 은하 위치로 변경

2. **Scene 3 줌아웃 속도 개선**
   - 타깃 은하에서 전체 은하단으로 확장되는 구간을 **기존 대비 1.5배 빠르게** 조정
   - 이에 따라 Scene 3 텍스트 등장과 Scene 4 진입 시점도 앞당겨 재정렬

3. **폰트 변경**
   - 기본 UI/타이틀 글꼴을 **UnTaza.ttf**로 교체
   - 디버그/개발 보조 텍스트는 기존 시스템 폰트 유지

4. **Scene 4(v15) 유지**
   - 두 번째 물고기 떼 경로 수정
   - 고래 1.5배 확대 및 느린 이동
   - 고래 등장 이후 구간 1.3배 확장
   - 대왕오징어 더 크게 등장
