## 주소
GitHub Pages 기준:
`https://<사용자명>.github.io/unknown-world/display/`

## 구현 범위
- Jeremy Thomas 고해상도 우주 사진을 16:9 모니터 배경으로 사용
- Firebase Realtime Database `publicResponses` 실시간 감지
- 첫 질문은 중앙에 크게 표시
- 질문이 늘어날수록 기존 질문은 자동 축소되고 화면 전체로 분산
- 위치는 랜덤처럼 보이지만 response id 기반으로 안정적으로 결정
- 새 질문은 4초 동안 중앙 오버레이 + 해당 별 생성 애니메이션으로 강조
- 질문 50개 이상부터 star-only 모드
  - 기존 질문 텍스트는 숨김
  - 별은 유지
  - 새 질문만 4초간 중앙에 텍스트로 표시된 뒤 별만 남음
- Firebase에서 질문 삭제 시 화면에서도 즉시 제거
- 기존 모바일 페이지는 변경하지 않음

## 아직 포함하지 않은 기능
- 관리자 로그인/응답 관리
- 추첨 화면
- 당첨 15초 자동 복귀
