# Display v26 — 상시 질문 시각화

- Firebase `publicResponses`를 `createdAt` 기준 최신 100개만 구독합니다.
- 신규 질문은 중앙에서 약 4초간 크게 표시된 후 분산 배치에 합류합니다.
- 초기 100개 로딩 시에는 신규 질문 애니메이션을 실행하지 않습니다.
- 관리자 숨김/영구삭제로 질문이 제거되면 대형 화면에서도 즉시 사라집니다.
- 101번째 질문이 추가될 때 DB 원본을 삭제하지 않고 화면의 oldest 항목만 자동 제외합니다.
- 추첨/당첨자 overlay 및 `displayState/currentWinner` listener를 제거했습니다.
- 중앙 하단에 `관람객이 남기고 간 질문들` 문구가 고정 표시됩니다.
- 질문 DOM은 최대 100개로 제한되어 장시간 운영 시 무한 증가하지 않습니다.
