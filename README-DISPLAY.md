# Display v2 — 질문 중심 시각화

## 변경사항
- 질문별 별 아이콘을 완전히 제거했습니다.
- 50개 이상에서 텍스트를 숨기던 star-only 모드를 제거했습니다.
- 질문 수가 늘수록 글자 크기가 단계적으로 작아집니다.
- 최소 글자 크기는 18px로 제한해 무한히 작아지지 않도록 했습니다.
- 질문 수가 많아질수록 질문 블록의 최대 폭도 함께 줄어듭니다.
- 신규 질문은 화면 중앙에서 약 4초간 크게 강조된 뒤,
  기존 질문들과 같은 크기로 화면의 분산 배치에 합류합니다.
- 우주 배경은 64초 주기로 매우 천천히 이동/확대되어
  정적인 배경이 아니라 우주를 부유하는 듯한 느낌을 냅니다.
- `prefers-reduced-motion` 환경에서는 배경 애니메이션을 자동으로 끕니다.

## Firebase
기존과 동일하게 `publicResponses`를 실시간 감지합니다.
삭제된 질문은 화면에서도 즉시 제거됩니다.
